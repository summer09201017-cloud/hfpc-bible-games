■ ⚠ 地雷（接手務必守）
  1. GitHub 是唯一真相；一律在 hfpc-git 的 clone 工作；文件跟程式一起 commit；動手前先確認在哪個分支/有沒有別的 session。
  2. 併 main = Netlify 自動部署（paul/大廳/約拿正式站）。約拿正式站別放動作關原型（會曝光）；動作關走 war-games 或保羅 ?demo。
  3. 牧者把關：未審文案別當定稿；新產題/文案一律牧者審。
  4. .bat 純英文 ASCII + CRLF（.gitattributes 已鎖）；啟動 `npm run dev -- --open "/?demo=KEY"`；別寫 Unix 的 >/dev/null（要 nul）。
  5. 卡片 spec 的 answer/lives 不可越界；過 validate / npm test。
  6. Node 24 vite build 偶爾無聲死：先刪 dist 再 build。Netlify(Node 20)不受影響。
  7. 零美術檔：改完場景一定截圖（保羅 Playwright）或跑 headless 渲染檢查（約拿）驗收。
  8. 約拿 level：7 摩西、8 紅海、9 聖歌、10 反轉；feat/redsea 才有這些（刻意不併約拿 main）。
  9. 保羅 src/minigames/jonah/ 是 sync:jonah 的 verbatim 複製；改動作關手感改約拿端再 sync，別直接改保羅那份。
 10. 多 session：未 commit 的檔會被別人 `git clean` 清掉——做完即 commit+push；共用工作樹各用 worktree。
